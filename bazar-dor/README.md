# Bazar Dor

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের আজকের ও বাজারভিত্তিক দাম দেখার বাংলা web app।

## Features

- আজ দাম বেড়েছে ও কমেছে—এমন পণ্যের তালিকা
- পণ্যের category অনুযায়ী দাম দেখা ও sort করা
- প্রতিটি পণ্যের বিভিন্ন বাজারের দামের পরিসর
- Bengali interface এবং Dhaka timezone-এর তারিখ
- Email ও password দিয়ে sign up/sign in
- User profile এবং profile update
- Responsive product, category ও profile pages

## Technologies

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Better Auth
- SQLite
