# Bazar Dor

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের আজকের দাম, বাজারভিত্তিক দাম, এবং পণ্যের ওঠানামা দেখার বাংলা web app।

## Features

- Homepage-এ পণ্যের দাম ও পরিবর্তনের তথ্য
- Category অনুযায়ী পণ্য দেখা ও সাজানো
- Product details এবং বিভিন্ন বাজারের দাম
- Sign up, sign in, এবং profile page
- Bengali interface ও Dhaka timezone অনুযায়ী তারিখ
- Better Auth এবং SQLite-ভিত্তিক local authentication

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- SQLite

## Requirements

- Node.js
- npm
